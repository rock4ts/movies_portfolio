### Функциональные требования

На основании бизнес-требований к сервису сбора пользовательских действий были сформулированы следующие функциональные требования.

#### 1. Отслеживание кликов

- Сервис должен предоставлять API для приема событий кликов от клиентских приложений.
- Сервис должен принимать и обрабатывать события кликов пользователя по элементам интерфейса, включая фильмы, трейлеры, категории и другие ключевые элементы сайта.

#### 2. Отслеживание просмотров страниц

- Сервис должен принимать и обрабатывать события просмотра страниц.
- Сервис должен принимать информацию о типе или идентификаторе просматриваемой страницы.
- Сервис должен принимать информацию о времени пребывания пользователя на странице.

#### 3. Отслеживание кастомных событий

##### 3.1. Смена качества видео

- Сервис должен принимать и обрабатывать события смены качества воспроизводимого видео.
- Сервис должен фиксировать каждое изменение качества воспроизведения.

##### 3.2. Просмотр видео до конца

- Сервис должен принимать и обрабатывать события просмотра видео до конца.

##### 3.3. Использование фильтров поиска

- Сервис должен принимать и обрабатывать события использования фильтров поиска.
- Сервис должен принимать информацию о примененных параметрах фильтрации.

#### 4. Обработка событий

- Сервис должен выполнять валидацию поступающих событий на соответствие установленному формату и обязательным параметрам.
- Сервис должен передавать успешно обработанные события в брокер сообщений для последующей асинхронной обработки.
- Сервис должен формировать сообщение об ошибке при получении некорректных данных или невозможности обработки события.
